# 方心免費基本貼圖包：靜態原型 v1

## 狀態

- 用途：CoupleSpace 第一方免費基本貼圖包的第一輪視覺原型。
- 形式：8 張無文字、透明背景的靜態 PNG，單張 `1254 × 1254 px`。
- 角色基準：`docs/design/01-brand-identity.md` 與
  `docs/design/assets/fangxin-character-sheet-concept.png`。
- 製作方式：以生成式角色參考圖產生單張動作，再以 chroma key 移除背景。
- 發布邊界：尚未完成一致向量重建、小尺寸聊天室實機辨識、深色背景、色彩 token、
  無障礙對比、品牌／商標近似性與公開發布查核，不視為可直接上架的最終素材。

| 檔案 | 情境 | 設計意圖 |

| `08-goodnight.png` | 晚安 | 坐下休息、眼睛柔和閉起 |

## 共通視覺規則

- 保留深靛紫後片、柔珊瑚前片、中央暖琥珀光窗與頭頂 Moment 光點。
- 臉只有兩個小方眼，不使用固定嘴巴。
- 不使用愛心、聊天泡泡、性別化符號、戀愛績效或催促語意。
- 使用薄暖白外框，讓貼圖在深色與淺色聊天背景中維持輪廓。
- `source/` 保留背景移除前的 chroma-key 來源，供重新去背與設計追溯；App 不應直接載入該資料夾。

## 下一步驗證

1. 在 120、96、72 與 48 pt 顯示尺寸檢查眼睛、手勢及 Moment 光點辨識度。
2. 以實際聊天深色／淺色背景檢查暖白外框、光暈與邊緣殘色。
3. 若方向成立，再以一致幾何與正式色彩 token 重建可發布版本。
