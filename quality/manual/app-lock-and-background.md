# LOCK-001：App Lock、背景與重新啟動

目前實作以使用者主動啟用為預設：帳號設定開啟後，App 進入 inactive 或 background 立即遮蔽私密內容；回到 active 時以 Face ID 或裝置密碼驗證。驗證取消、失敗或無法使用時維持遮蔽，不登出、不解除配對，也不變更待送內容。此本機實作不代表本清單已通過。

## 步驟與預期

1. 在「我們 → 帳號設定」啟用「使用 Face ID 或裝置密碼解鎖」。確認私密內容立即被鎖定，且系統提示可以使用 Face ID 或裝置密碼。
2. 啟用後，冷啟動、背景逾時返回與裝置鎖定後返回都先驗證再顯示私密內容。
3. Face ID／裝置驗證取消、失敗、暫時鎖定與重試都有清楚狀態，不造成 session 或資料遺失。
4. App switcher snapshot、通知與背景畫面不洩漏聊天、照片、Moment 或答案。
5. 驗證成功後回到原安全流程，不重複傳送待送內容。
6. 未啟用 App Lock 的使用者維持正常啟動；升級不會擅自改變設定。

任一未驗證便顯示私密內容、無法安全退出或驗證流程造成資料重送都阻擋發布。
