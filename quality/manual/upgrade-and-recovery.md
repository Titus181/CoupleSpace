# UPGRADE-001：升級、換機與資料恢復

## Release candidate 升級

1. 在舊 build 建立配對、聊天、照片、Moment、回應、答案、名稱、狀態與可用的離線待送項目。
2. 不清除 App 資料，直接安裝 release candidate。
3. 確認帳號與 relationship 不重建；遠端內容數量、正文、照片、時間、順序與關聯一致。
4. 恢復網路後，舊待送項目只送達一次且順序正確。
5. 舊版與新版若可能同時存活，驗證向後相容讀寫；不相容時必須阻擋發布並有明確 rollout 計畫。

## 換機／重裝

1. 使用第二支已清除本機狀態的真實 iPhone，以同一測試帳號登入。
2. 不重新配對，恢復本人可存取的 relationship 與完整遠端歷史。
3. 逐類核對數量、時間、順序、照片可讀性與 Moment／問答／聊天關聯。
4. 再執行一次刪除 App 後重裝，重複驗證。
5. 明確記錄仍只存在原遺失裝置 Outbox 的內容不保證恢復，UI 不得把它標成已同步。

## Database／Storage restore drill

- 從同一恢復點還原 database 與 Storage，核對 metadata、object 與引用一致。
- 記錄可恢復範圍、資料時間點與無法恢復的缺口；「備份功能已啟用」不算通過。

任一靜默清空、重複、錯序、關聯斷裂、照片缺失或要求使用者重新配對都阻擋發布。
